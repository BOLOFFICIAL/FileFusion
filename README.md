# FileFusion

**FileFusion** — это легковесное Windows Forms приложение для объединения содержимого множества текстовых файлов в один. Идеально подходит для подготовки контекста к передаче языковым моделям (LLM), создания бэкапов кода или анализа логов.

## Возможности

*   **Рекурсивный обход папок:** Программа собирает все файлы из выбранной директории, включая вложенные подпапки.
*   **Фильтрация по расширениям:** Автоматически определяет уникальные расширения файлов в папке. Вы можете выбрать только нужные типы (например, `.cs`, `.py`, `.txt`) и исключить бинарные файлы.
*   **Предпросмотр и выборочное слияние:** Позволяет точечно выбрать конкретные файлы для объединения.
*   **Структурированный вывод:** Каждый файл в итоговом документе обрамляется комментариями вида `//Начало файла:` и `//Конец файла:`, что упрощает навигацию.
*   **Экспорт:** Сохранение результата в текстовый файл (`.txt`) в кодировке UTF-8 с автоматической генерацией имени на основе даты и времени.

## Как это работает

1.  **Выбор источника:** Нажмите «Выбрать папку» (или выберите пункт меню «Файл»), чтобы указать директорию с исходниками.
2.  **Фильтрация по типу:** В левом списке `Расширения` отметьте нужные группы файлов. Вы можете использовать чекбокс «Все», чтобы выбрать всё сразу.
3.  **Выбор файлов:** В правом списке `Файлы` укажите конкретные документы, содержимое которых нужно объединить.
4.  **Предпросмотр:** Текст появится в нижней части окна. Если данных слишком много, программа предложит сразу сохранить их в файл, не загружая в оперативную память для предпросмотра.
5.  **Сохранение:** Нажмите «Сохранить в файл», чтобы экспортировать результат.

## Системные требования

*   **ОС:** Windows 7 и выше.
*   **Фреймворк:** .NET 6.0/8.0 (Windows Forms) или .NET Framework 4.7.2+ (в зависимости от целевой платформы при сборке).
*   Для запуска может потребоваться установленный [.NET Runtime](https://dotnet.microsoft.com/en-us/download/dotnet).

## Установка и запуск

### Вариант 1: Запуск скомпилированного релиза
1.  Скачайте последнюю версию `FileFusion.zip` из раздела [Releases](https://github.com).
2.  Распакуйте архив в удобное место.
3.  Запустите `FileFusion.exe`.

### Вариант 2: Самостоятельная сборка
```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/FileFusion.git

# Перейдите в папку проекта
cd FileFusion

# Соберите проект (пример для .NET SDK)
dotnet build -c Release

# Запустите
dotnet run
```

## Использование с ChatGPT / LLM

FileFusion отлично подходит для подготовки промптов:
1.  Выберите корневую папку вашего небольшого программного проекта.
2.  Выберите только текстовые расширения (`.cs`, `.xaml`, `.json`, `.csproj` и т.д.).
3.  Нажмите «Сохранить», чтобы получить единый файл.
4.  Загрузите этот файл в чат или скопируйте его содержимое с префиксом: *«Проанализируй код и структуру моего проекта на основе следующего склеенного файла:»*.
